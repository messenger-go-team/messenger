# Веб-клиент

Стек по [SPEC](../docs/SPEC.md): React, TypeScript, Tailwind CSS и shadcn/ui.
Язык интерфейса - русский.

Экраны MVP: вход, регистрация, список чатов, окно чата и профиль.
Для каждого экрана предусмотрены мобильная, планшетная и десктопная раскладки.

Инициализация приложения и выбор инструментов сборки выполняются в
[T17](https://github.com/messenger-go-team/messenger/issues/17).
Команды установки зависимостей, разработки и сборки будут добавлены вместе
с приложением и lock-файлом.

Для работы до готовности бэкенда запланированы REST-моки по OpenAPI
([T19](https://github.com/messenger-go-team/messenger/issues/19)) и мок
WebSocket-сервера
([T20](https://github.com/messenger-go-team/messenger/issues/20)).
