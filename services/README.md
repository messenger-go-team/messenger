# Go-сервисы

Монорепозиторий содержит три сервиса с границами ответственности из
[SPEC, раздел 6](../docs/SPEC.md).

| Каталог | Ответственность | Таблицы во владении |
| --- | --- | --- |
| `auth/` | Пользователи, токены и контакты | `users`, `refresh_tokens`, `contacts` |
| [chat/](chat/README.md) | WebSocket-соединения и доставка событий | Собственных таблиц нет |
| `history/` | Чаты, участники, сохранение и выдача сообщений | `chats`, `chat_members`, `messages` |

chat сохраняет сообщения через gRPC-вызов history. history назначает `seq`
и обеспечивает идемпотентность по `client_msg_id`. Доступ к чатам определяется
членством в `chat_members`, включая личные чаты с двумя участниками.

Готовый [шаблон сервиса](_template/README.md) находится в `_template/` (T06).
Из корня: `make build`, `make lint`, `make test`. Сервисы создаются копированием
шаблона; инструкция, переменные окружения и ограничения описаны в его README.
Все сервисы входят в один корневой Go-модуль. Версия Go указана в
`go.mod` и используется в CI. Проверки и локальные команды описаны в
[docs/ci.md](../docs/ci.md).
