# Go-сервисы

Монорепозиторий содержит три сервиса с границами ответственности из
[SPEC, раздел 6](../docs/SPEC.md).

| Планируемый каталог | Ответственность | Таблицы во владении |
| --- | --- | --- |
| `auth/` | Пользователи, токены и контакты | `users`, `refresh_tokens`, `contacts` |
| `chat/` | WebSocket-соединения и доставка событий | Собственных таблиц нет |
| `history/` | Чаты, участники, сохранение и выдача сообщений | `chats`, `chat_members`, `messages` |

chat сохраняет сообщения через gRPC-вызов history. history назначает `seq`
и обеспечивает идемпотентность по `client_msg_id`. Доступ к чатам определяется
членством в `chat_members`, включая личные чаты с двумя участниками.

Каркас сервиса и команды сборки, линтинга и тестирования появятся в
[T06](https://github.com/messenger-go-team/messenger/issues/6).
Версия Go и схема модулей будут зафиксированы при добавлении Go-проекта
и согласованы с CI.
