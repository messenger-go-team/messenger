## Фактические результаты

- Закончены `AUTH-01`, `AUTH-05`, `AUTH-14`, `WS-02`, `MSG-03`, `CONTACT-02`, `LATER-07`. В четырёх вспомогательных API/WSS-сериях зафиксировано 196 HTTP-запросов, включая подготовку и очистку данных.
- MSG-03. В исходном журнале после `idempotency_conflict` найден GET History с HTTP 200. Исходные `message_id`, `seq`, время создания и SHA-256 текста совпали. Запрос уже входит в 196 запросов.
- LATER-06. Сохранены последовательные и параллельные статусы Save, стабильность ID, одна активная запись и результат сравнения итогового срока с ответом обновления 200. Точные `created_at`, `due_at` и `updated_at` для сверки в исходном журнале отсутствуют. Кейс отмечен Not run до повторного прогона с записью полей.
- Later в открытом приложении. Save вернул 201, срок наступил в 18:47 МСК, свежий GET показал статус `due`, затем в UI наблюдалось напоминание.
- Later после повторного открытия. A отправил просьбу. B отложил её до 19:04 МСК и закрыл вкладку в 19:00:32. Приложение открыли в 19:04:12, напоминание с правильной просьбой наблюдалось в 19:04:33. Из него открыли исходное сообщение и отправили ответ. «Готово» убрало запись, после reload список оставался пуст. GET /later от A в 19:01:47, пока запись B была активна, её не содержал. Сетевые ответы браузера B в этом сеансе не записывались.
- Отдельный переход к старому сообщению. Цель имела `seq=1`, последняя страница до ответа содержала `22..71`. После новой загрузки чата целевой строки не было. Переход из Later открыл ту же цель ровно один раз. Проверка подтверждает пользовательский переход. Для полного LATER-13 остаются догрузка в обе стороны и контролируемый WS-дубль на предусмотренной кейсом фикстуре.
- Контакты. Проверены локальный поиск по подстроке в двух регистрах, исключение своего аккаунта и исчезновение дубля после добавления контакта. Для двух разных пар открыты чаты из контактов и из поиска. Повтор каждого действия сохранил ID чата, поиск не добавил контакт. HTTP 201/200 и тела запросов этих четырёх действий не захвачены. После удаления тестового контакта сохранились история и возможность отправить сообщение.
- На экране поиска контактов ширины 360/768/1440 CSS px совпали с шириной документа. Кнопки были доступны, Tab перевёл фокус на кнопку добавления. Литеральный вывод четырёх тестовых строк проверен до и после reload. Эти наблюдения описаны в строках CONTACT-15, WEB-01/02 и WS-03 вместе с оставшимися вариантами.
